# F1 Race Intelligence Demo

A standalone static demo website. Open `index.html` in a browser to preview it locally.

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` to the root of the repository.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for the published URL shown by GitHub Pages.

The page embeds its chart images and driver data, so no backend is required.
